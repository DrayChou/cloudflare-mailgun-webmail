# Changelog

## 0.1.0 - 2026-07-26

- Initial public release
- Cloudflare Workers, D1, and R2 deployment
- Multi-account email login and administrator mailbox creation
- Per-account inbox, sent mail, message, and attachment isolation
- Mailgun sending, inbound webhook, stored-message polling, and manual sync
- Responsive webmail UI and password management
- Reply, forward, CC, BCC, multiple recipients, and outbound attachments
- Partial Cloudflare Email Routing and Email Sending support
